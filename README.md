# basic-keylogger
This is my first attempt at creating a keylogger. It is only used for educational purposes and developing a greater understanding of how computers interact with each other.

The python code is dependent on the keyboard package.

Snake game code written by freegames python package

CSkeyloggerproject.py is the code for the keylogger

snakeGame.py is the code for the game

snakeGameLauncher.py runs both of the above python scripts

I use the subprocess package in the launcher in order to run both scripts and give root access to the keylogger
